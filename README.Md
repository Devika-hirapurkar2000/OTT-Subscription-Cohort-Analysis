# OTT Subscription Cohort and Retention Analysis

## Project Overview
This project analyzes OTT subscription data to understand customer subscriptions, retention, cancellations, and revenue trends.

The objective is to identify customer behavior patterns and generate useful business insights to support data-driven decisions.

## Project Objectives
- Analyze total and active subscribers.
- Understand customer cancellation patterns.
- Perform cohort analysis.
- Calculate customer churn rate.
- Analyze subscription revenue.
- Build an interactive Power BI dashboard.

## Tools and Technologies
- **SQL:** Data querying and analysis
- **Python:** Data cleaning and exploratory data analysis
- **Power BI:** Interactive dashboard and visualization
- **Excel / CSV:** Dataset management

## Dataset
The project uses an OTT subscription dataset containing customer and subscription information.

Key columns include:
- Customer ID
- Subscription Date
- Cancellation Date
- Country
- Device
- Subscription Plan
- Monthly Fee
- Subscription Status
- Cohort Month

## Project Workflow

1. Data collection and understanding
2. Data cleaning and preprocessing
3. Exploratory data analysis using Python
4. SQL queries for customer and subscription analysis
5. Cohort and retention analysis
6. Power BI dashboard development
7. Business insights and conclusions

## Key KPIs
- Total Subscribers
- Active Subscribers
- Cancelled Subscribers
- Monthly Revenue
- Average Monthly Fee
- Churn Rate

## Project Files
- `ott_analysis.py` – Python analysis
- `ott_analysis_queries.sql` – SQL queries
- `ott_dashboard.pbix` – Power BI dashboard
- `ott_subscriptions_1000.csv` – Subscription dataset
- `ott_subscriptions_clean.csv` – Cleaned dataset

## Business Value
This analysis helps understand subscriber behavior, identify cancellation trends, monitor revenue, and support customer retention strategies.
